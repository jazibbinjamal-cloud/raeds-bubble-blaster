# Raed's Bubble Blaster

A bubble shooting game designed and drawn by Raed, age 6, on paper and a whiteboard, and brought to life with Claude.

**Play:** https://jazibbinjamal-cloud.github.io/raeds-bubble-blaster/

Works in any browser on phones, tablets and computers. On a phone you can add it to the home screen to play full screen like an app (iPhone: Share → Add to Home Screen; Android Chrome: menu → Install app).

## Levels
1. Pop 28 bubbles in 2 minutes. A teacher stops by to cheer you on.
2. Moving barriers take away a point if you hit them.
3. A zig-zag ghost: if it touches you, you're OUT.
4. A naughty kid races you for the bubbles and steals the ones you aim at.
5. A naughty girl blows all the bubbles off the screen every few seconds.

The blaster holds 6 pellets, then takes 2 seconds to reload.
